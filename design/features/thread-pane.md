# Reading a long thread

The default is a scrollable chat card. Keep it: Inkling already hangs a stitched tag
from the words, and replacing that object would break the relationship with the note.
The important change is its boundary, not a new surface treatment.

Two alternatives: a paper index card has a fixed face, an edge, and a back, but paging
messages across its faces makes comparing replies harder. A terminal pager keeps a
command line below a moving transcript, supports long lines, and follows new output
until you scroll away. Borrow that last behavior inside the existing tag.

The conversation moves; the mind's name and the reply stay in place. The reader can
look back through an answer and redirect it without hunting for the bottom. That is
the useful moment, and the authored detail: arriving words respect the reader's scroll
position while the composer remains reachable.

Keep the notebook's paper, ink, lettering and stitched edge. Markdown introduces only
reading structure: short headings, small paragraph gaps, code on paper, real links.
The card grows naturally for short conversations, stops below 560 pixels, and gets
shorter with the window. Sending during an answer always steers; there is no mode menu.
